# 🪐 GoetiaDex - Desafio Alpar Rocket

O **GoetiaDex** é uma aplicação web interativa desenvolvida para catalogar e explorar os 72 daemons da Goetia. O projeto combina uma estética esotérica refinada com funcionalidades modernas de front-end, focado em alta performance e usabilidade.

## 🛠️ Matriz Tecnológica (Arquitetura)

| Tecnologia | Responsabilidade | Conceito Aplicado |
| :--- | :--- | :--- |
| **HTML5** | Estruturação Semântica | Organização hierárquica do DOM. |
| **CSS3** | Estilização e UI | Design responsivo e Dark Mode. |
| **Vanilla JS** | Lógica de Negócio | Algoritmos de filtragem e manipulação de estado. |
| **Bootstrap 5** | Framework de Layout | Grid System e componentes interativos (Modais). |
| **SVG** | Gráficos Vetoriais | Interface interativa da Árvore da Vida. |

## 🌟 Funcionalidades de Destaque

- **Navegação Esotérica:** Filtre os daemons por títulos hierárquicos clicando diretamente nas Sephiroth da Árvore da Vida.
- **Influência do Dia:** Sistema de sorteio aleatório com feedback visual de tremor (shake) e brilho neon, simulando a canalização de energia.
- **Busca Dinâmica:** Filtro de pesquisa em tempo real por nome.
- **Responsividade Total:** Interface adaptada para smartphones, tablets e desktops.
